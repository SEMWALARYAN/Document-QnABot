# 📄 Document Q&A Bot

An AI-powered Document Question & Answering web application built with **Streamlit**, **LangChain**, and **Google Gemini**. Upload any PDF document and ask questions to get precise, context-grounded answers generated by Google's latest Gemini models.

---

## 🌟 Features

- **PDF Ingestion & Text Splitting:** Automatically extracts and chunks text using `PyPDFLoader` and `RecursiveCharacterTextSplitter`.
- **Semantic Vector Search:** Computes dense vector embeddings using Google's `gemini-embedding-2` model and indexes them in an in-memory vector database (`InMemoryVectorStore`).
- **Grounded Q&A Generation:** Retrieves the most relevant document chunks and synthesizes accurate answers using `gemini-3.8-flash`.
- **Interactive Web Interface:** Clean and responsive UI powered by Streamlit with real-time spinners and document reset controls.
- **Secure Configuration:** Environment variables are separated and protected from version control.

## 🏗️ Architecture & Workflow

```text
[ Upload PDF ]
      │
      ▼
[ PyPDFLoader ] ──► Extracts text from pages
      │
      ▼
[ RecursiveCharacterTextSplitter ] ──► Chunks text (chunk_size=1000, overlap=200)
      │
      ▼
[ GoogleGenerativeAIEmbeddings ] ──► Generates vector embeddings (gemini-embedding-2)
      │
      ▼
[ InMemoryVectorStore ] ◄── Index chunks for similarity search
      │
      ├───────────────────────────────┐
      │ (User submits query)           │
      ▼                                ▼
[ Similarity Search ] ──► Retrieves Top-K relevant chunks
      │
      ▼
[ Gemini 3.8 Flash LLM ] ──► Generates grounded answer from context
      │
      ▼
[ Streamlit UI Display ]
```

## 🚀 Getting Started

### Prerequisites

- Python 3.10+ (Python 3.12+ recommended)
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey)

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/Document-QnABot.git
cd Document-QnABot
```

### 2. Set Up a Virtual Environment

It is recommended to run the project in an isolated virtual environment:

```bash
# Create virtual environment
python3 -m venv env

# Activate virtual environment
# On macOS/Linux:
source env/bin/activate
# On Windows (cmd):
# .\env\Scripts\activate.bat
# On Windows (PowerShell):
# .\env\Scripts\Activate.ps1
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file in the project root by copying `.env.example`:

```bash
cp .env.example .env
```

Open `.env` and paste your Google API key:

```env
GOOGLE_API_KEY="your_actual_google_api_key_here"
```

> [!WARNING]
> Never commit your `.env` file to GitHub! The `.gitignore` file is pre-configured to keep your API keys private.

### 5. Run the Application

Launch the Streamlit app:

```bash
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`.

## 🔒 Security & Git Best Practices

Before pushing this repository to GitHub, verify that your `.env` file is excluded from staging:

```bash
# Check git status
git status
```

You should see `.env` listed as ignored (or not appearing under untracked files). Only `.env.example`, `.gitignore`, `app.py`, `requirements.txt`, and `README.md` should be staged for commit:

```bash
git add app.py requirements.txt README.md .gitignore .env.example
git commit -m "Initial commit: Document Q&A Bot with Gemini and Streamlit"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo-name>.git
git push -u origin main
```
